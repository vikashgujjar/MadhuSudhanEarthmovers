# Madhusudhan Earthmover ERP

The ERP is the PHP/Laravel app in **[laravel/](laravel/README.md)**. It runs on Hostinger shared hosting;
see [laravel/deploy/HOSTINGER.md](laravel/deploy/HOSTINGER.md) to put it live.

`tools/tailwindcss.exe` (not committed) rebuilds the CSS; see the Laravel README.

The earlier Python/Django version was removed. It is still in the git history (commit `7bb1f47`).
